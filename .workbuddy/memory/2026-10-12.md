# 第三十八轮：有序合成配方（泥土 + 铁 → 全能饰品）

用户给的图案：
```
泥土 铁 空
空   空 空
泥土 泥土 泥土
```
→ 1 个全能饰品。

## 新增 2 个数据文件

- `src/main/resources/data/omnitrinket/recipes/omni_trinket.json`
- `src/main/resources/data/omnitrinket/advancements/recipes/misc/omni_trinket.json`（配方书解锁）

配方（严格按图，3×3）：

```json
"pattern": ["DI ", "   ", "DDD"]
"key": { "D": {"item": "minecraft:dirt"}, "I": {"item": "minecraft:iron_ingot"} }
"result": { "item": "omnitrinket:omni_trinket" }   // count 默认 1
```

★ "铁" 按 **铁锭 `minecraft:iron_ingot`** 处理（若用户其实想要铁块，改一行即可）。

## 1.20.1 数据包格式要点（照原版 fishing_rod / beacon 抄的）

- shaped 配方顶层字段：`type` / `category` / `key` / `pattern` / `result` / `show_notification`。
  `category` 与 `show_notification` 在 1.20.1 原版数据里就有，照抄没问题。
- 路径必须是 `data/<ns>/recipes/`（**复数**；1.21 起才改单数 `recipe/`）。
- 配方书解锁需要配套 advancement：
  `data/<ns>/advancements/recipes/<category>/<name>.json`，
  criteria = `inventory_changed`(材料) + `recipe_unlocked`，`rewards.recipes` 指向配方，
  并含 `sends_telemetry_event: false`。
- **图案里整行/整列为空是合法的**：原版靴子就是 `["X X","X X"]`（中间整列为空）。

## javap 核实的事实

- `ShapedRecipe.matches(CraftingContainer, Level)` 会依次试
  `matches(inv, x, y, true)` 和 `matches(inv, x, y, false)`
  ⇒ **镜像摆法同样能合成**（铁摆在泥土左边也可以）。
- 1.20.1 **没有**独立的 `ShapedRecipePattern` 类（那是后续版本），图案逻辑在 `ShapedRecipe` 里，
  且**不会**裁剪空行/空列 ⇒ 图案宽度 = 行字符串长度，空格 = 要求该格必须为空。

## 校验

两张 JSON 语法 OK；结构校验脚本全过（3×3、各行等宽、图案字符全部有定义、
产物 id 与 `OmniTrinket.OMNI_TRINKET` 注册名一致）；`compileJava` BUILD SUCCESSFUL。
本轮纯数据驱动，无 Java 改动。
